### Building the AAR using Android Studio:

-   Open your Android project in **Android Studio**.
-   Ensure you've selected the library module in the **Project** pane.
-   Click on `Build` in the menu.
-   Choose `Build Bundle(s)/APK(s)` -> `Build APK(s)`.

### Building the AAR using Command Line:

`./gradlew :assembleRelease`
